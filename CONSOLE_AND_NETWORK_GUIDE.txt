STAYEASE: BROWSER NETWORK TAB + BACKEND SERVER LOGS

This version uses real HTTP requests to an Express REST API.

START:
1. Extract the ZIP.
2. Open the extracted project folder in VS Code.
3. Run `npm install` once.
4. Run `npm run dev`.
5. Keep the terminal open. It runs Vite (frontend) and Express (backend).
6. Open the Vite URL shown in the terminal (normally http://localhost:5174).

CHROME NETWORK TAB:
1. Press F12 and open Network.
2. Select Fetch/XHR.
3. Tick Preserve log if you want requests to remain visible when the page changes.
4. Clear the list, then refresh the page.
5. You should see GET /api/hotels.
6. Log in, create a booking, edit guests, or cancel a reservation.
   You should see GET /api/reservations, POST /api/reservations,
   PATCH /api/reservations/<id>, and DELETE /api/reservations/<id>.
7. Click a request to inspect Headers, Payload, Preview, and Response.

SERVER LOGS:
The same API calls and status codes are printed in the VS Code terminal by Express.
Reservations are stored in reservations.json in the project root.
